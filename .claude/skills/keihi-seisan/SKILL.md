# 経費精算

領収書・レシートから**精度の高い経費精算伝票**を作る。
領収書を受け取ったら、以下のルールで「項目（勘定科目）」と「現場名」を決める。

## 1. 項目分類

| 内容 | 項目 |
|---|---|
| 駐車場・コインパーキング | **駐車代** |
| 電車・バス・地下鉄など（運賃・ICチャージ等） | **交通費** |
| ゴルフ（プレー代・コンペ代など） | **接待交際費** |
| 飲食（会食・食事・喫茶など） | **接待交際費** |
| 協力会などの参加費・会費 | **接待交際費** |
| 材料（資材・部材・消耗材など、施工に使う物） | **材料代** |
| 工具（工具・電動工具・計測器など） | **工具代** |
| 講習（講習会・技能講習・特別教育など）の受講料 | **講習代** |

## 2. 現場名のルール

| 条件 | 現場名 |
|---|---|
| 講習代 | **社内** |
| 関東防災設備 安全衛生協力会の参加費・会費 | **安全衛生協力会** |
| お客さん（元請・取引先）の協力会の参加費・会費 | **その会社名**（例：〇〇建設の協力会 → 「〇〇建設」） |
| 上記以外 | 領収書・ユーザー申告の現場名を使う |

## 3. 精度を保つための運用

- 分類・現場名が領収書から判断できない場合は、推測で埋めずに**ユーザーに確認する**。
  （例：飲食なのか個人の昼食なのか、材料か工具か迷う物、現場名が不明なもの）
- 金額は領収書の**税込合計**を使う。日付・支払先・金額は読み取った値をそのまま転記し、読み取れない箇所は「要確認」と明記する。
- 同じ領収書の二重計上がないか（日付・支払先・金額が同一のもの）をチェックする。
- 伝票の最後に**項目別合計**と**総合計**を出す。

## 4. 伝票の出力形式（基本）

| No | 日付 | 支払先 | 内容 | 項目 | 現場名 | 金額（税込） | 備考 |
|---|---|---|---|---|---|---|---|

## 仕上げ

- 作り終えたら、ユーザーに渡す前に `teishutsu-check` で見直す（数字・日付・名前を元の資料と照合）。
