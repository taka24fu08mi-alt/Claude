# 業務日報（野口茜）

- 野口茜の業務日報を作成する。
- 書式は「業務日報_福島.xlsm」（Googleドライブ「04_日報→残業管理」フォルダ）に合わせる。
- 業務内容があいまいな場合は推測で埋めず、ユーザーに確認する。
- 人物・上司の情報は CLAUDE.md の「共通ルール（組織・人物）」を参照する。

## 書式（業務日報_福島.xlsm より）

- 1ファイル＝1か月（締め期間：21日〜翌月20日）。「日報」シートは16ページ、1ページに2日分。
- **報告は2日間に1回、上長に提出する**（書式の注記「★報告は２日間に１回上長に提出の事」）。

### 1日分の項目（上から順）

| 項目 | 書き方 |
|---|---|
| 氏名 | 野口茜 |
| 日付 | 令和〇年〇月〇日（曜）。平日／休日は自動 |
| 勤務区分 | 空欄＝出勤。代休／有休／AM有休／PM有休／夏季休暇／年末年始特別休暇 |
| 客先（現場名）・開始・終了・業務内容 | 1行1件、最大10行。時刻は「8:00」「17:30」形式 |
| 残業時間 | 平日残業・平日深夜・休日残業・休日深夜・60h超え・休憩・遅早・日計・月累計（自動計算） |
| 酒気帯び確認 | 運転前／運転後の確認時間・検知器使用・酒気帯び・体調、車両No.、確認者 |
| 連絡事項・特記事項 | 自由記入 |
| 押印欄 | 承認1・確認4 |

### 客先欄の特別な書き方

- 「休憩」：その時間を残業から差し引く
- 「直行」「直帰」：片道1時間30分を超えた分を残業に計上
- 「遅刻」「早退」：書いた日だけ差し引き（客先・業務内容・連絡事項のどこかに書く）

### 残業の集計ルール（自動計算。確認用）

- 定時 9:00〜17:30。平日 5:00〜9:00・18:00〜22:00＝平日残業、22:00〜翌5:00＝深夜
- 17:30〜18:00は残業に入れない
- 30分単位で切り捨て。月累計60時間を超えた分は「60h超え」
- 代休1日＝7.5h控除。AM有休＝3h・PM有休＝4.5h勤務扱い

## 野口茜の日報の決まり

- 作成ファイル：「業務日報_野口.xlsm」（Googleドライブ「04_日報→残業管理」）。福島の書式をコピーし、氏名を野口茜にしたもの。日報はこのExcelに記入する形で作る。
- 客先（現場名）欄：**書かない**（空欄）。ただし「休憩」「直行」「直帰」「遅刻」「早退」は残業計算に使うので、必要なときだけ書く。
- 酒気帯び確認・車両No.：**記入する**。
- 押印の順番：野口（本人・I列）→ 中井主任（確認・H列）→ 稲川参事（確認・G列）→ 越前（確認・F列）→ 安藤（承認・E列）
- 押印マクロは福島用のままのため、`押印マクロ変更手順_野口.md` の変更が必要（Excelで管理者が行う）。

## タイムカード集計との連携

- 「56期_タイムカード集計.xlsm」のマクロ「日報取込」が、日報の「タイムカード転記」シートを読み、月シートの**氏名の列**に残業を記入する。
- 野口の列は、R8年10月〜R9年8月の各月シートの右端（BC〜BI列、見出し「事務／野口」）に追加済み（2026-11-06）。R8年9月は古い書式のため追加していない。
- 氏名は「野口」で照合される（日報の氏名「野口茜」に「野口」が含まれていればOK）。

## 仕上げ

- 作り終えたら、ユーザーに渡す前に `teishutsu-check` で見直す（数字・日付・名前を元の資料と照合）。
