# 業務日報（野口茜）

- 野口茜の業務日報を作成する。
- 書式は「業務日報_福島.xlsm」（Googleドライブ「04_日報→残業管理」フォルダ）に合わせる。
- 業務内容があいまいな場合は推測で埋めず、ユーザーに確認する。
- 人物・上司の情報は CLAUDE.md の「共通ルール（組織・人物）」を参照する。

## 書式（業務日報_福島.xlsm より）

- 1ファイル＝1か月（締め期間：21日〜翌月20日）。「日報」シートは16ページ、1ページに2日分。
- **報告は2日間に1回、上長に提出する**（書式の注記「★報告は２日間に１回上長に提出の事」）。

### 1日分の項目（上から順）

| 項目 | 書き方 |
|---|---|
| 氏名 | 野口茜 |
| 日付 | 令和〇年〇月〇日（曜）。平日／休日は自動 |
| 勤務区分 | 空欄＝出勤。代休／有休／AM有休／PM有休／夏季休暇／年末年始特別休暇 |
| 客先（現場名）・開始・終了・業務内容 | 1行1件、最大10行。時刻は「8:00」「17:30」形式 |
| 残業時間 | 平日残業・平日深夜・休日残業・休日深夜・60h超え・休憩・遅早・日計・月累計（自動計算） |
| 酒気帯び確認 | 運転前／運転後の確認時間・検知器使用・酒気帯び・体調、車両No.、確認者 |
| 連絡事項・特記事項 | 自由記入 |
| 押印欄 | 承認1・確認4 |

### 客先欄の特別な書き方

- 「休憩」：その時間を残業から差し引く
- 「直行」「直帰」：片道1時間30分を超えた分を残業に計上
- 「遅刻」「早退」：書いた日だけ差し引き（客先・業務内容・連絡事項のどこかに書く）

### 残業の集計ルール（自動計算。確認用）

- 定時 9:00〜17:30。平日 5:00〜9:00・18:00〜22:00＝平日残業、22:00〜翌5:00＝深夜
- 17:30〜18:00は残業に入れない
- 30分単位で切り捨て。月累計60時間を超えた分は「60h超え」
- 代休1日＝7.5h控除。AM有休＝3h・PM有休＝4.5h勤務扱い

## 要確認（野口茜の場合）

- 事務員のため、客先（現場名）欄・酒気帯び確認・車両No.を使うか
- 押印欄（承認・確認）にだれが押すか（中井主任・稲川参事・越前）
- 出力の形（Excelに記入するか、文字で下書きを出すか）
