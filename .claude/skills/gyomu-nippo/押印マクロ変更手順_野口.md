# 押印マクロ変更手順（業務日報_野口.xlsm）

「業務日報_野口.xlsm」の押印マクロは、福島さん用のまま（福島・上田・越前・安藤）になっている。
野口茜の日報で押印を使うには、Excelで以下の変更を1回だけ行う（管理者パスワードが必要）。

## 押印欄の割り当て（変更後）

| 列 | 欄 | 押す人 | 押す順番 |
|---|---|---|---|
| I | 確認（右端） | 野口（本人） | 1 |
| H | 確認 | 中井 主任 | 2 |
| G | 確認 | 稲川 参事 | 3 |
| F | 確認 | 越前 | 4 |
| E | 承認 | 安藤 | 5 |

## 手順

1. 「業務日報_野口.xlsm」をExcelで開き、`Alt + F11` でVBAエディタを開く
2. 左の一覧から **modStamp** をダブルクリック
3. `Ctrl + H`（置換）で、下の「置換1〜4」を順に行う
4. 下の「書き換え1〜2」のとおり、2か所を手で直す
5. 保存して閉じ、もう一度開く
6. 「管理者メニュー」→「1：パスワードの再設定」で、**野口・中井・稲川** のパスワードを登録する
   （越前・安藤は今のパスワードのまま使える）

## 置換（Ctrl + H、「すべて置換」）

| No | 検索する文字 | 置換後の文字 | 件数の目安 |
|---|---|---|---|
| 1 | `福島,上田,越前,安藤` | `野口,中井,稲川,越前,安藤` | 4か所 |
| 2 | `For l = lvl + 1 To 4` | `For l = lvl + 1 To 5` | 1か所 |
| 3 | `For l = 4 To lvl Step -1` | `For l = 5 To lvl Step -1` | 1か所 |
| 4 | `ColOfLvl = Choose(lvl, 9, 8, 7, 5)` | `ColOfLvl = Choose(lvl, 9, 8, 7, 6, 5)` | 1か所 |

## 書き換え1：BoxInfo の中（「欄の定義」の下）

変更前：

```vb
        Case 9: lvl = 1: nms = "福島"
        Case 8: lvl = 2: nms = "上田"
        Case 7: lvl = 3: nms = "越前"
        Case 5: lvl = 4: nms = "安藤"
```

変更後：

```vb
        Case 9: lvl = 1: nms = "野口"
        Case 8: lvl = 2: nms = "中井"
        Case 7: lvl = 3: nms = "稲川"
        Case 6: lvl = 4: nms = "越前"
        Case 5: lvl = 5: nms = "安藤"
```

## 書き換え2：Menu_StampAll の中（「まとめて押印」）

変更前：

```vb
        Case "福島": col = 9
        Case "上田": col = 8
        Case "越前": col = 7
        Case "安藤": col = 5
```

変更後：

```vb
        Case "野口": col = 9
        Case "中井": col = 8
        Case "稲川": col = 7
        Case "越前": col = 6
        Case "安藤": col = 5
```

## 確認

- 「管理者メニュー」→「5：改ざんチェック」で「問題ありません」と出ればOK
- 試しに1日分を記入して、野口→中井→稲川→越前→安藤の順に押せるか確認する
