# 提出前チェック（見直し）

Anthropic Academy「AI Fluency」の **Discernment（見極め）** と、「Claude Code in Action」の **検証用スキル（Verification Skills）** を元にしたチェック。
作ったものをユーザーに渡す前に、下の表を**上から順に**確かめる。

## チェック表

| # | 見るところ | 確かめ方 |
|---|---|---|
| 1 | **数字**（金額・時間・枚数） | 元の資料（領収書・メール・カレンダー）と1つずつ照らし合わせる。合計は計算し直す |
| 2 | **日付・曜日** | 日付と曜日が合っているか、和暦・西暦の変換が正しいか（今日の日付は日本時間で確認） |
| 3 | **人名・会社名・現場名** | 漢字の間違いがないか。CLAUDE.md の人物表・元の資料と同じ書き方か |
| 4 | **推測で埋めた所** | 元の資料に無いことを書いていないか。あれば「要確認」と印をつけてユーザーに聞く |
| 5 | **抜け** | 頼まれた項目・必須項目（書式の欄）が全部埋まっているか |
| 6 | **送り先・宛先** | メール・予定なら、宛先・出席者・時間帯が正しいか |
| 7 | **外に出るもの** | 社外に出す文面・削除・変更は、内容を見せて許可を取ってから（CLAUDE.md の「必ず守ること」） |

## 報告のしかた（短く）

- 問題なし → 「✅ 見直し済み（数字・日付・名前OK）」と一言そえる。
- 気になる所あり → 箇条書きで「どこが」「なぜ気になるか」を出し、直す前にユーザーに確認する。
- 確かめられなかった所（元の資料が見られない等）は、**確かめられなかった**と正直に書く。
