# 出退勤アプリ（試作）

会社全体で使う出退勤・作業日報・タイムカード一覧のWebアプリ。スマホ・PCのブラウザで使う。

## 動かし方

```
cd kintai-app
npm install
npm start          # http://localhost:3000
npm test           # 残業計算のテスト
```

初回起動時に管理者（社員番号 `admin`）を作り、パスワードを画面に表示する。
`ADMIN_PASSWORD` を指定するとそのパスワードで作る。

## できること

| 画面 | 内容 |
|---|---|
| 打刻 | 出勤・退勤ボタン（日本時間。日付をまたぐ退勤にも対応） |
| 日報 | 勤務区分・業務内容（10行）・酒気帯び確認・連絡事項 |
| タイムカード | 締め期間（前月21日〜当月20日）の一覧と残業集計 |
| 管理 | 今日の出勤状況・打刻の修正・社員登録（管理者だけ） |

残業計算は「業務日報_福島.xlsm」のルールに合わせている（`lib/overtime.js`）。

## まだやっていないこと

- 祝日・会社カレンダー（今は土日のみ休日）
- 直行・直帰・遅刻・早退の計算、代休・有休の時間控除
- 日報の承認・押印の流れ
- Excel（タイムカード集計.xlsm）への出力
- ログイン失敗の回数制限、本番サーバーへの設置
